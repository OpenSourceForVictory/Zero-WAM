# 真机推理页签

本地实现，部署时须同时更新 `web_console.py`、`web_console.html`、`inference_console.py`；依赖已有 `enable_zero.py` 和 `inference_client`。应在没有采集、遥操或推理运行时重启网页服务。

界面从 `inference_client/zeroshot_oct21/validation_manifest.json` 加载 V01–V12，选择后填入该示教的 prompt。每次换示教必须重新布置场景并确认。模式包括检查、仅预测、真机执行；默认检查、一个 chunk，0 表示连续执行。默认使用本机 SSH 隧道端口 39057。页面不启动或重启模型服务器。

使用前结束采集会话并退出双臂控制；需要时在机械臂控制页使能归零。确认启动会解除软件停止，调用已有 `inference_client/run.sh`，固定 piperpika 动作协议和视频/示教 guidance 1/5，传递所选 latent 路径和 prompt。不自动归零或切换示教。其他客户端控制参数沿用既有默认值。

网页推理运行期间禁止其他控制、录制和转换动作；另外持有归零及重定位锁，并检查已有控制进程。不要通过终端另开控制程序。

停止按钮写入软件停止并向本次客户端发 SIGINT，等待客户端清理和保存。不发送下电、失能或电子急停命令。只有进程确实退出后运行状态才结束。网页服务退出时也请求停止自己启动的推理。

每次运行保存请求、命令及客户端日志至 `inference_client/inference_logs/web/<时间>/`，客户端下级目录保留原有实拍和诊断输出；服务端预测仍保存在服务端配置的 prediction 根目录。启动失败及退出码显示在界面。

验证：网页状态、输入校验、采集互斥和停止入口使用模拟测试验证，不驱动机械臂。部署后的实际连接及停止行为应再通过检查模式和受控真机测试验证。
